## 🧠 תיאור הפרויקט

שני שחקנים מתחילים בפינה השמאלית-תחתונה של הלוח, והמטרה שלהם היא להגיע למשבצת הניצחון בפינה הימנית-עליונה.  
במהלך הדרך, השחקנים פוגשים משבצות עם השפעות שונות: סכנה שמורידה חיים, ריפוי שמחזיר חיים, ולבה שאינה עבירה כלל.

האתגר המרכזי הוא לבחור במסלול **המהיר ביותר** שמאפשר לשרוד את הדרך – תוך שימוש באלגוריתם **A\*** שמחשב את המסלול לפי תוואי המשבצות ומצב הבריאות של השחקן.

במצב מול מחשב (AI), האלגוריתם שונה – המחשב שוקל מתי "לחכות" על משבצות ריפוי כדי להבטיח הישרדות במסלול.
